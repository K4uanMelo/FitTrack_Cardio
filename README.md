# Descrição
O aplicativo vai permitir que o usuário selecione o tipo de atividade que pretende realizar e quando iniciar o treino, o aplicativo passará a contabilizar informações como tempo de atividade, distância percorrida e velocidade média. Ao finalizar o exercício, os dados serão organizados em um registro de treino, que ficará armazenado em um histórico para consultas posteriores.
O FitTrack busca oferecer uma forma simples e centralizada de registrar atividades físicas ao ar livre, reunindo dados como distância, tempo e frequência dos treinos para facilitar o acompanhamento do desempenho do usuário. 
O aplicativo será desenvolvido em React Native, permitindo criar o aplicativo para Android e iOS com uma única base de código e acesso aos recursos do smartphone. O projeto poderá utilizar Expo e Expo Router para facilitar o desenvolvimento e a navegação, Expo Location para obter a localização do usuário durante os treinos e AsyncStorage para salvar o histórico das atividades diretamente no dispositivo.
